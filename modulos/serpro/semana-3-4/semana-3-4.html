módulo 02 · parte 1

Engenharia de Software e DevOps

cai todo concurso Contêineres — Engine vs Orquestração
Pegadinha principal do Edital: A banca separa estritamente o Docker como ferramenta de "Engine" e o Kubernetes/OpenShift como ferramentas de "Orquestração"[cite: 652]. Misturar esses conceitos resulta em perda de pontos.
Docker (Engine) Plataforma que empacota, distribui e gerencia contêineres individuais. Responsável por construir a imagem e rodar o contêiner isolado no sistema host[cite: 652].
K8s (Orquestração) Kubernetes automatiza a implantação, o dimensionamento e o gerenciamento de aplicações em contêineres em um cluster. Ele gerencia múltiplos "Dockers", garantindo resiliência e balanceamento[cite: 652].
alta incidência Versionamento e CI/CD
CI (Integração) Continuous Integration: Prática de realizar merges frequentes do código em um repositório centralizado, acionando builds automatizados e testes unitários. Foco: Qualidade do código.
CD (Entrega/Deploy) Continuous Delivery (Entrega) vs Continuous Deployment (Implantação). Na Entrega, o deploy em produção é manual; na Implantação, é totalmente automatizado.
cai todo concurso Qualidade de Código e Testes
O que a Cebraspe cobra: Diferenciar o escopo de cada teste[cite: 656, 657]. Mocks e Stubs pertencem aos testes unitários. Carga e estresse são Testes de Requisitos Não Funcionais (RNF).
Teste UnitárioTesta o menor componente isolado do sistema (ex: uma função ou classe). Utiliza Mocks (objetos programados para verificar interações) e Stubs (respostas fixas)[cite: 656].
Teste de IntegraçãoAvalia se múltiplos módulos/componentes do sistema funcionam corretamente quando agrupados[cite: 656].
Teste de RNFRequisitos Não Funcionais. Avaliam "como" o sistema faz. Engloba Teste de Carga (volume esperado) e Teste de Estresse (volume acima da capacidade até o colapso)[cite: 657].
módulo 02 · parte 2

Arquitetura, Frontend e Backend

cai todo concurso Padrões de Microsserviços
A banca exige a compreensão de transações distribuídas em microsserviços[cite: 664, 665]. O Cebraspe gosta de cobrar SAGA e CQRS.
SAGAPadrão para lidar com transações distribuídas. Ao invés de um grande "commit" (impossível entre múltiplos bancos separados), executa uma sequência de transações locais. Se uma falha, dispara transações de "compensação" para reverter[cite: 664].
CQRSCommand Query Responsibility Segregation. Separa as operações de leitura (Query) das operações de escrita (Command). Permite escalar leitura e escrita de forma independente[cite: 664].
API GatewayPonto de entrada único que roteia as requisições dos clientes para os microsserviços adequados, atuando como orquestrador de serviços e facilitando a segurança/monitoramento[cite: 664].
alta incidência Padrões Frontend: SPA e PWA
SPASingle Page Application. Carrega uma única página HTML e atualiza o conteúdo dinamicamente via Ajax (JSON) sem recarregar a página inteira. Exemplos de frameworks: React, VueJS, Angular[cite: 645, 646].
PWAProgressive Web App. Aplicações web que oferecem experiência nativa (instalação no celular, notificações push) e funcionamento offline (via Service Workers)[cite: 646].
cai todo concurso SOLID e Clean Code
S - Single Respons.Uma classe deve ter apenas uma razão para mudar (uma única responsabilidade).
O - Open/ClosedAberta para extensão, fechada para modificação. Use herança/polimorfismo ao invés de alterar o código já existente[cite: 662].
L - LiskovSubclasses devem ser substituíveis pelas suas superclasses sem quebrar o sistema.
I - Interface Segreg.Múltiplas interfaces pequenas são melhores que uma interface generalista.
D - Dependency Inv.Módulos de alto nível não devem depender de baixo nível. Ambos devem depender de abstrações.
módulo 02 · parte 3 · Conhecimentos Específicos/Básicos

Segurança da Informação e LGPD

cai todo concurso Padrões ISO 27000 — Os Três Pilares (CID)
Mnemônico Clássico Cebraspe: CID (Confidencialidade, Integridade e Disponibilidade). O edital explicitamente aborda Confiabilidade/Confidencialidade, Integridade e Disponibilidade[cite: 632]. Se a banca incluir um quarto pilar como "exclusivo" da ISO 27000, o item estará errado.
ConfiabilidadeGarante que a informação seja acessível apenas àqueles autorizados a ter acesso (Confidencialidade)[cite: 632]. Criptografia é a principal ferramenta.
IntegridadeSalvaguarda a exatidão e a completude da informação e dos métodos de processamento[cite: 632]. Hashes e assinaturas digitais são mecanismos de proteção.
DisponibilidadeGarante que os usuários autorizados tenham acesso à informação e aos ativos sempre que necessário[cite: 632]. Balanceamento de carga e backups garantem isso.
média-alta incidência OWASP Top 10
O que é?Um documento de conscientização padrão para desenvolvedores e segurança de aplicações web, listando os riscos de segurança mais críticos[cite: 636].
Injeção (SQLi)Dados não confiáveis são enviados a um interpretador (ex: banco de dados). Mitigação: Parameterized queries (Queries preparadas).
XSSCross-Site Scripting. Atacante injeta scripts maliciosos (geralmente JS) em sites confiáveis. Mitigação: Escapar/sanitizar inputs.
cai todo concurso LGPD (Lei nº 13.709/2018)
Classificado no edital como "Legislação acerca de privacidade" (Conhecimentos Básicos)[cite: 627].
Dado PessoalInformação relacionada a pessoa natural identificada ou identificável (Ex: Nome, CPF, IP, Geolocalização).
Dado SensívelDado sobre origem racial/étnica, convicção religiosa, opinião política, saúde, vida sexual, dado genético ou biométrico. O tratamento é MUITO mais restrito[cite: 627]. Dica: Dados financeiros/bancários NÃO são dados sensíveis pela LGPD.
TratamentoToda operação realizada com dados pessoais: coleta, produção, recepção, classificação, utilização, acesso, etc.
